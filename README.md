# WandererJournal

> 这是一款Material You风格的极简日记APP，功能干净纯粹，让您随时随地都能记录生活中的点滴。

## ✨特性一览


| 特性           | 说明                                                                                    |
|----------------|-----------------------------------------------------------------------------------------|
| **聊天式日记** | 以类似于聊天的形式记日记，写日记时像发消息，读日记时像看消息。                          |
| **情绪标注**   | 通过情绪标签标记写下日记时的心情及其强烈程度。                                          |
| **内容搜索**   | 读日记时支持根据日记内容和标签搜索日记，且支持在多个符合搜索条件的日记段落之间跳转。    |
| **日记分享**   | 允许选中若干日记段落进行分享，支持以图片形式分享日记。                                  |
| **角色管理**   | 可以像在电话本新建联系人一样新建角色，并在日记中引用，方便用户记忆日记中提到过的角色。  |
| **数据管理**   | 支持将数据导出为压缩包以及从压缩包中导入数据，可实现记账规则的分享和数据备份等功能。    |
| **隐私保护**   | 开启隐私保护功能后，每次进入APP都需要通过屏锁进行身份验证。此功能需要设置锁屏验证方式。 |

## 🛡️需要使用的权限

| 权限名称                 | 说明                                         |
|--------------------------|----------------------------------------------|
| **相机权限**             | 允许调用系统相机拍照                         |
| **通知权限**             | 允许在忘记记日记时发送通知提醒               |
| **自启动权限**           | 允许在后台启动并自动执行任务                 |
| **“无限制”电池优化策略** | 降低被杀后台的几率，确保自动任务能够正常运行 |
| **精确闹钟权限**         | 允许设置精确定时任务，用于自动触发某些功能   |

## 🎗️使用建议

- APP支持Android 9及以上的设备，推荐使用不低于Android 12的设备以获得最佳的使用体验。
- 部分国产系统即便授予通知权限也无法弹出横幅通知，需要手动进入通知设置允许发送横幅通知。
- 若使用的是定制安卓系统（如HyperOS、ColorOS等），请授予自启动权限以确保软件能够自启动，否则部分自动化功能会失效。
